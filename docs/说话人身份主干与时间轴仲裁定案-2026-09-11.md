## 0. 结论(TL;DR)

1. 风暴起点的三个症状,病理各不相同:**时间轴漂移**已被骨架锚定基本控制(症状最轻);**字幕划分**是物理切分与展示规则的张力(独立问题);**说话人标签错误**是结构性故障(症状最重),根因有三:全局 pyannote 通道因依赖缺失而断线、事件级聚类对短话轮存在结构性偏向、上游合并在无说话人信息时抹掉换人边界。
2. 修复不动摇"骨架分段主干"(2026-09-11 姊妹文档已定),而是插入**两个共识层**:
   - **层1 身份共识层**:全局 speaker turns 从后处理第 0 步**前置到分离之后**;骨架区间 × turns 求交得到说话人标注的原子段;字幕事件在 turn 翻转点做**词级后切分**,标签先天正确。
   - **层2 时间轴仲裁层**:把散落的吸附/重投影/能量检测/覆盖审计收敛为一张三规则信任策略表(§4.3),核心原则:**骨架管段级真值,ASR 管词级真值,能量检测当裁判,文本一致性决定信任级别**。
3. 管线线性顺序不推翻,变化只有一处位置移动(turns 前置)+ 两个共识层。
4. 说话人模型**不提高时间戳数值精度**(其 turn 边界 ±100~200ms,比骨架粗两个数量级),但它提供骨架盲区(无静音换人)的边界证据,吸附到最近词间隙后达到词级精度——是"边界存在性"的净增益,不是数值精度增益。

素材画像:**多人为主**(采访、影视剧、TTS 生成、短视频、口播),分钟级,GPU 可能可用但先 CPU 验证。

## 4. 设计

### 4.1 架构总览

```
分离(现状)
  → [层1] 全局 pyannote turns(前置,一次,结果进缓存)
  → 骨架提取 unified_ffmpeg_pass(现状)
  → [层1] spans = 骨架区间 × turns(reconcile_regions 接线)
  → ASR 窗口 = 物理聚合(现状不变,窗口可跨说话人,上下文优先)
  → 逐窗口 ASR(现状)
  → [层1] 词级后切分 @ turn 翻转点(事件诞生,标签先天正确;重叠标 overlapped)
  → [层2] 时间轴仲裁表(R1/R2/R3)
  → 帧级衔接(现有 speaker 检查开始真正生效)/去重/输出(现状)
  → [退役] 后处理事件级聚类 → 降级为校验诊断
```

### 4.2 层1:身份共识层

核心解耦原则(项目已有经验的形式化,同 `group_speech_intervals` + `member_projection` 模式):

> **ASR 窗口 ≠ 字幕事件。**音频窗口保持物理连续、上下文完整(ASR 引擎吃上下文,宁大勿小);字幕事件在识别完成后按 turn 翻转点做词级后切分。

三种情况分诊:

| 窗口内情况 | ASR 输入 | 字幕事件 |
| --- | --- | --- |
| 单一说话人(常见快路径) | 整段识别 | 事件链整段继承该标签,零切分开销 |
| 中途换人、无静音间隙 | **仍整段识别**(切音频毁上下文) | turn 边界吸附最近词间隙,词级切分,各自标签 |
| 两人重叠 | 整段识别 | 事件标 `overlapped`,不强判归属,进复核队列 |

换人边界精度:pyannote turn(±100~200ms)→ 吸附最近词间隙(词级 ±20~80ms)。

前置后新增成本:每任务一次全音频 pyannote 推理。CPU 分钟级素材约几十秒;diarization 缓存(`cache/diarization/cache.db`)对重复任务零成本。

降级链保持现状分层:global(pyannote)→ embedding(ECAPA/pyannote.embedding)→ MFCC 凝聚聚类回退(silhouette<0.15 收敛单说话人)→ unknown。TTS/口播等单人素材自动短路:全局 turns 归一后 ≤1 个说话人时跳过切分与多说话人路径。

### 4.3 层2:时间轴仲裁表

概念前提:骨架(silencedetect)**只产时间区间不产文本**。"骨架识别到了 X"的实际含义是骨架窗口 pass 的 ASR 认出了 X。因此仲裁不是两个"文本"互比,而是分粒度协作:

| 规则 | 区域特征 | 仲裁策略 | 相对现状的增量 |
| --- | --- | --- | --- |
| **R1 共识** | 分段基线文本(骨架窗口 pass 的 ASR 结果)与全程识别 evidence 文本按区域字符对齐**一致**,但 ASR 词时间漂移 | 段边界**整段信骨架**(吸附解除 `max_snap_distance` 限幅,直接钳到骨架成员段端点);词内时刻仍用 ASR | 现行吸附限幅 0.25~0.5s,漂移超界修不动;S1 实测 global 时间轴中位偏差 −0.16s、p90 0.53s,超界漂移真实存在 |
| **R2 盲区** | ASR 词落在骨架"静音区"(底噪重/气声/低音量) | **禁止吸附**(重投影无物理成员可钳,吸附只会裁掉真语音);改用 `rms_energy_check` 能量确认:确认为真→保留 ASR 词时间,事件标 `skeleton_blind`;无法确认→按幻觉裁剪(与 risk_scoring 阈值联动) | 现状 `rms_override` 只处理单点冲突;R2 是区域级策略 + 禁吸附保护 |
| **R3 空洞** | 骨架有语音、ASR 无词覆盖 | 复用覆盖审计 + LocalRecovery 局部重识别(现状已实现);新增与层1 联动:空洞也可能是 B 话轮被 A 事件吞掉,空洞区间叠加 turns 检查换人 | 空洞诊断从纯文本维度扩展到说话人维度 |

R1 参照文本来源:**不新增任何识别次数**——复用 `evidence_enabled: true` 已在每次任务运行的全程识别 evidence(姊妹文档 D1 决策"不添加校验功能"不被违反,该成本已在支付)。

与姊妹文档 D5 的边界:姊妹文档规定"global 独有句不自动补入字幕"(global 来源文本幻觉率高);R2 处理的是**分段 ASR 自身**在骨架盲区的词,且有能量确认门槛,两者来源与置信结构不同,不冲突。

### 4.4 失效模式矩阵

| 场景 | 骨架行为 | turns 行为 | 仲裁层行为 |
| --- | --- | --- | --- |
| 快语速、句间无间隔 | silencedetect(0.1s)找不到静音→骨架退化为一整段大窗口,分段职责内移交窗口内 VAD+边界精修 | **补上骨架盲区的换人边界**(核心增量场景) | R1/R2 照常;180s+ 素材由 GlobalTranscriber 分窗保护 |
| 均匀底噪 | 自适应阈值(噪声底+10dB,钳[-45,-30])**最佳场景** | 正常 | 正常 |
| 非均匀噪声(分离后音乐残留/音效) | 全局阈值逐区域双向失效(漏切/误切) | 正常 | R2 能量仲裁逐点兜底;空洞进 R3 |
| 两人重叠说话 | 能量上不可分 | pyannote `overlapped` 标记 | 事件诚实标注,不强判归属,人工复核 |
| TTS/口播单人素材 | 正常 | turns ≤1 自动短路,零额外开销 | 正常 |
| pyannote 不可用(最小环境) | 不受影响 | 降级链 embedding→MFCC→unknown | **层2 不依赖说话人,独立生效** |

## 5. 决策记录(风暴收敛,2026-09-11)

| # | 决策点 | 选择 | 关键理由 |
| --- | --- | --- | --- |
| D1 | 管线顺序是否推翻重排 | **不推翻**;唯一位置移动是 turns 前置 | "物理层先行、语义层后置"双层结构正确;骨架/ASR/说话人各用在其擅长的层 |
| D2 | 全局 turns 是否前置 | **前置**到分离之后 | 层1 的一切(spans 求交、合并硬约束、词级切分)都依赖 turns 先在;CPU 分钟级成本可接受,有缓存 |
| D3 | ASR 窗口是否按说话人切分 | **否**;窗口保持物理聚合,事件词级后切 | ASR 上下文优先;用户"5-10s 单说话人段直接 ASR"的快路径作为窗口恰好单说话人时的自然涌现,不是窗口划分规则 |
| D4 | 换人边界精度来源 | turn 吸附最近词间隙 | 单独 turn ±200ms 不达标;吸附后词级;骨架在无静音处无边界,三者互补 |
| D5 | 事件级聚类去留 | **退役为校验诊断模式** | 词级归属先天正确后,聚类改为对照报告冲突(质量信号),不再是标签来源 |
| D6 | R1 参照文本来源 | 复用已支付的全程识别 evidence | 零新增推理;不违反姊妹文档 D1 |
| D7 | 骨架盲区文本是否自动入字幕 | **能量确认后方可保留** | 与姊妹文档 D5(global 独有不自动补)区分:R2 是分段 ASR 来源 + rms_energy_check 门槛 |
| D8 | 说话人模型是否提高时间轴精度 | **否**(直接回答风暴问题);它提供盲区边界证据 | 精度账本:骨架 ~1ms > 词级 ±20-80ms > turn ±100-200ms;增益在"边界存在性" |
