# 时间轴精度修复方案

## 问题根因

新版 `finalize.py` 在 `_split_long_events` 之前增加了 `strict_segmenter.segment_events()` 调用：

```
新版管线:  验证 → segment_events(按词边界预切分) → _split_long_events → 语义分组 → 显示映射
旧版管线:  验证 → _split_long_events → 语义分组 → 显示映射
```

### 问题机制

| 步骤 | 旧版行为 | 新版行为 | 影响 |
|------|---------|---------|------|
| `segment_events` | 无此步骤 | 将事件按词级时间戳预分割，生成大量 0.3-0.8s 的微事件 | 事件粒度极细 |
| `_split_long_events` | 处理 VAD 段事件，时长通常 >5s，触发内部的 `_split_into_utterances`（按句子边界拆分）和 `_group_utterances`（将短句合并至 ≥0.8s） | 处理已预分割的微事件，每个事件已远小于 5s/20字符 阈值，**直接跳过全部拆分和合并逻辑** | `_group_utterances` 合并逻辑永远不触发 |
| `_merge_short_events` | 存在但从未被调用 | 存在但从未被调用 | 碎片化无修复入口 |

### 三个落空的合并路径

1. **`_split_long_events` → `_group_utterances` (情况2)**：当单个 utterance < 0.8s 时向后合并 → 新版事件已低于拆分阈值，此路径不经过
2. **`_split_long_events` → `_group_utterances` (情况1)**：当单个 utterance > 5.0s 时强制按弱标点拆分 → 新版事件已远小于 5s，不触发
3. **`SubtitleBuilder._merge_short_events`**：专门用于合并 < 0.8s 短字幕的方法 → 两个版本都从未调用

## 修复方案

### 方案 A（推荐）：segment_events 后增加 _merge_short_events 合并步骤

```
修复后管线: 验证 → segment_events(按词边界预切分+物理裁剪) → _merge_short_events(合并至 ≥0.8s) → _split_long_events(兜底拆分) → 语义分组 → 显示映射
```

### 优点
- **最小改动**：仅修改 `finalize.py` 和维护调用参数 `pipeline_stage.py`
- **保留新版的物理裁剪改进**：`segment_events` → `_make_piece` 中的 `physical_spans` 裁剪逻辑继续工作
- **利用已有代码**：`_merge_short_events` 已实现完整的短事件合并逻辑（含说话人感知、间隙控制）
- **句子级输出**：合并后事件 ≥ 0.8s，后续 `_split_long_events` 可以正确按句子边界拆分和合并

### 修改清单

#### 1. `finalize.py` - `FinalizeConfig`
新增 `min_duration: float = 0.8` 字段。

#### 2. `finalize.py` - `finalize_subtitle_events()`
在 `segment_events()` 调用后、`_split_long_events()` 前，增加 `_merge_short_events()` 调用入口。

#### 3. `pipeline_stage.py` - `_finalize_events()`
传递 `SubtitleBuildConfig.min_duration` 给 `FinalizeConfig`。

### 不改动的模块

| 模块 | 原因 |
|------|------|
| `strict_segmenter.py` | 物理片段裁剪保留，词边界预切分逻辑保留 |
| `subtitle_builder.py` | 代码已完善，仅首次被正确调用 |
| Evidence Review 10 文件 | 与时间轴完全解耦，全部保留 |
| ASR、VAD、分离等 | 无影响 |

## 预期效果

| 指标 | 修复前 | 修复后 |
|------|--------|--------|
| 平均字幕时长 | 0.3-0.8s (词级) | 1.0-3.0s (句子级) |
| 字幕数量 | 大量碎片 | 合理数量 |
| ASR 幻觉控制 | ✅ Evidence Review 全链路 | ✅ 无影响 |
| 物理时间轴精度 | ✅ 物理裁剪保留 | ✅ 无影响 |
