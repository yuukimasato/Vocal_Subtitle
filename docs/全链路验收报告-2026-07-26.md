# Vocal_Subtitle 全链路验收报告

日期：2026-07-26

## 结论

代码链路已完成并通过无模型回归；WhisperX 已安装并完成 CPU global 全链路 benchmark。六个场景均实际使用 global，技术发布门通过，但字幕质量指标仍未达到高精度质量阈值。

## 已验证

- 全量测试：`venv/bin/pytest -q`，`597 passed`。
- CLI：`run --help` 暴露 `--asr-path auto|global|segmented`。
- WebUI/API：路径选择、任务结果和降级字段测试通过。
- `auto`：当前 CPU 环境成功使用 global；WhisperX 不可用时回退为 `legacy_degraded`，分类为 `dependency_unavailable`。
- `global`：当前 CPU 环境运行成功；全局失败时直接失败，不静默回退。
- `segmented`：显式 legacy 路径运行成功。
- 真实素材：`test/quality_manifest.yaml` 中 6 组音频与人工 ASS 全部可运行。

## 后续质量门

继续优化断句与内容完整性后执行：

```bash
venv/bin/python scripts/run_quality_benchmark.py \
  --manifest test/quality_manifest.yaml \
  --config configs/default.yaml \
  --asr-path global --require-global --ci \
  --output-dir test/benchmark_results/real_material/global-cpu-20260726-final
```

只有所有场景实际使用 `global` 且指标达到命令行指定的阈值时，质量报告才会标记为通过。`auto` 发生 fallback、`global` 依赖缺失或素材类别不完整都会保持未通过；当前仅技术 global 门通过。
