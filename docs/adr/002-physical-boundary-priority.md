# ADR-002: 物理边界优先

**状态**: 已实施
**日期**: 2026-08-02
**决策者**: yuukimasato

## 背景

字幕系统需要处理多种时间边界：VAD 语音段、ASR 词级时间戳、声学骨架（ffmpeg silencedetect）、说话人变更点、语义合并边界等。若无统一的物理边界权威来源，将导致：
- 字幕跨越硬静音区域
- 不同引擎对"语音范围"的定义不一致
- 后处理在无约束情况下随意调整时间

## 决策

1. **`PhysicalTimeline` 是物理边界的权威来源**：所有语音/非语音边界判定以 `PhysicalTimeline` 为准，其证据来自 ffmpeg 声学骨架和 VAD 检测结果。

2. **字幕不能跨越硬静音**：任何字幕事件的最大时间范围受限于其所在的物理 bin。语义合并、角色标注、格式化不能绕过物理边界。

3. **物理覆盖审计是必选步骤**：每次生产运行必须执行 `audit_physical_coverage`，检测遮盖空白、过分配和欠分配。

4. **物理字幕分箱优先于启发式分段**：`build_physical_subtitle_bins` 按物理语音间隔自动分箱，替代启发式事件操作，减少碎片化。

5. **词级物理分配强制执行**：ASR 词级时间戳通过 `allocate_words` 分配到物理跨度，`repair_late_words` 修复迟到词。

## 后果

- 后处理模块（语义合并、格式化、角色标注）只能在物理边界内组织展示
- 任何扩展时间轴的优化（如帧级无缝衔接）必须经过声学校验门控
- 物理层变更会影响所有下游模块，需要全面回归测试
- 维护者需要理解物理时间线 IR 结构才能修改时间相关逻辑
