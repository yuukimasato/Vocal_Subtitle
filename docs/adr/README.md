## 状态说明

- **提案**: 方案讨论中，尚未决策
- **已接受**: 决策已确认，尚未全面实施
- **已实施**: 决策已在代码中全面执行
- **部分实施**: 核心逻辑已实现，边缘场景或配套流程待完善
- **已废弃**: 被后续 ADR 替代或不再适用
- **仅供参考**: 历史记录，不作为当前规范

## 新建 ADR 流程

1. 在 `docs/adr/` 下创建 `NNN-title-slug.md`
2. 按模板填写：背景、决策、后果、相关
3. 更新本索引表
4. 关联代码变更需在 commit 中引用 ADR 编号
