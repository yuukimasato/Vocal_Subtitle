# 场景模板使用指南

vocal-subtitle 提供了 5 种预配置的场景模板，覆盖常见的音频处理需求。
每个模板针对特定场景优化了参数配置，可直接使用或作为自定义配置的基础。

## 快速使用

```bash
# 查看可用模板列表
vocal-subtitle profiles

# 使用模板处理文件
vocal-subtitle run input.mp3 -o output.srt --profile <模板名称>
```

## 模板详解

### 1. default — 通用模板

**适用场景**：不明确的音频类型，作为基线配置。

| 阶段 | 引擎 | 关键参数 |
|------|------|----------|
| 分离 | UVR (BS-Roformer) | 高品质分离 |
| VAD | Silero | threshold=0.5 |
| 合并 | — | gap=0.4s, max_len=30s |
| ASR | faster-whisper large-v3 | CUDA, float16 |
| 说话人分离 | 关闭 | — |
| 角色标注 | 关闭 | — |

**特点**：
- 平衡速度与精度
- 不做特殊优化，适用于大多数场景
- 不锁定语言，自动检测
- 默认不启用说话人分离和角色标注

```bash
vocal-subtitle run audio.mp3 -o output.srt --profile default
```

---

### 2. podcast — 播客/访谈模板

**适用场景**：1-3 小时的播客、访谈、对谈类音频。

| 阶段 | 引擎 | 关键参数 |
|------|------|----------|
| 分离 | UVR (BS-Roformer) | 高品质分离 |
| VAD | Silero | threshold=0.4（捕获更多语音） |
| 合并 | — | gap=0.4s, padding=0.08s |
| 说话人分离 | SpeakerDiarizer | 开启，distance=0.5 |
| 角色标注 | RoleLabeler (LLM) | 开启，deepseek-v4-pro |
| ASR | faster-whisper large-v3 | 锁定中文 |

**特点**：
- 使用 UVR 最高品质分离引擎
- 稍低的 VAD 阈值，减少漏检
- 较小的 padding，避免混入背景
- 锁定中文，识别更精准
- 字幕紧凑（18 字/行）
- **默认开启说话人分离 + LLM 角色标注**，自动识别主持人和嘉宾身份

```bash
vocal-subtitle run podcast.mp3 -o podcast.srt --profile podcast
```

---

### 3. education — 教学/演讲模板

**适用场景**：课程录播、学术演讲、TED 风格讲座。

| 阶段 | 引擎 | 关键参数 |
|------|------|----------|
| 分离 | Spleeter | 教学场景背景音少 |
| VAD | Silero | threshold=0.5, silence=600ms |
| 合并 | — | gap=0.6s, min_len=1.0s |
| ASR | faster-whisper large-v3 | 不锁定语言 |

**特点**：
- 使用 Spleeter 即可（背景音通常不多）
- 较大的合并阈值和静音间隔，适合慢语速
- 不锁定语言，支持中英混合课程
- 较长的字幕时长（6s max），适合阅读
- 更多文字容量（24 字/行）

```bash
vocal-subtitle run lecture.mp3 -o lecture.srt --profile education
```

### 4. variety_show — 综艺/直播模板

**适用场景**：综艺节目、直播录像等含丰富背景音的视频。

| 阶段 | 引擎 | 关键参数 |
|------|------|----------|
| 分离 | UVR (BS-Roformer) | 最强分离能力 |
| VAD | Silero | threshold=0.35（防漏检） |
| 合并 | — | gap=0.3s, max_len=25s |
| 说话人分离 | SpeakerDiarizer | 开启，distance=0.5 |
| 角色标注 | RoleLabeler (LLM) | 开启，deepseek-v4-pro |
| ASR | faster-whisper large-v3 | 锁定中文 |

**特点**：
- UVR 强力分离，应对复杂背景音
- 极低的 VAD 阈值（0.35），防止笑声/音效导致漏检
- 短段长限制（25s），快节奏场景
- 小 padding（0.05s），减少背景音混入
- 快速字幕切换（0.6-4.0s）
- 开启降噪（noise_reduction）
- **默认开启说话人分离 + LLM 角色标注**，适合多人综艺/访谈场景
- **建议开启 LLM 优化**来修正识别错误

```bash
vocal-subtitle run variety.mp3 -o variety.srt --profile variety_show --llm-optimize
```

---

### 5. music_live — 音乐现场模板

**适用场景**：演唱会、音乐节、Live House 等现场音乐视频。

| 阶段 | 引擎 | 关键参数 |
|------|------|----------|
| 分离 | UVR (BS-Roformer) | 必须最强引擎 |
| VAD | Silero | threshold=0.3（极低） |
| 合并 | — | gap=0.5s, max_len=25s |
| ASR | faster-whisper large-v3 | 锁定中文 |

**特点**：
- 必须使用 UVR 最强分离引擎
- 极低 VAD 阈值（0.3），音乐中人声极易漏检
- 最小语音时长降至 150ms，捕获短促的唱词
- 开启降噪（noise_reduction）
- 短字幕（0.5-4.0s），适应歌曲节奏

```bash
vocal-subtitle run concert.mp3 -o concert.srt --profile music_live
```

## 自定义模板

你可以创建自己的场景模板：

```bash
# 1. 复制现有模板
cp configs/podcast.yaml configs/my_template.yaml

# 2. 编辑参数
vim configs/my_template.yaml

# 3. 使用自定义模板
vocal-subtitle run input.mp3 -o output.srt --profile my_template
```

或在 Python 代码中构建自定义配置：

```python
from vocal_subtitle.config import (
    PipelineConfig, ASRConfig, VADConfig, SeparationConfig,
    DiarizationConfig, SpeakerRoleConfig, SubtitleBuildConfig,
)

config = PipelineConfig(
    separation=SeparationConfig(engine="uvr"),
    vad=VADConfig(engine="silero", threshold=0.45),
    asr=ASRConfig(engine="faster-whisper", model="medium", device="cpu"),
    diarization=DiarizationConfig(enabled=True, min_speakers=2, max_speakers=4),
    speaker_role=SpeakerRoleConfig(enabled=True, context_hint="a podcast interview"),
)
```
