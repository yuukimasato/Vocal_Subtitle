## 第 4 步：峰值 + 内置 VAD + provider 契约（Tier 1–4）

**任务**

- [x] 4.1 `agent/wav.js`：纯 JS WAV 解析（PCM 8/16/24/32 与 float32，多声道下混），合成 fixture 工具函数（16kHz mono、已知静音结构常量表）
