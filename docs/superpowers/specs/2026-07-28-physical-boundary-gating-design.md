# 物理边界方向与置信度门控设计

日期：2026-07-28

状态：已确认，待实施

## 1. 目标

修复复杂语音场景下声学校验可能造成的字幕结束时间后移，同时降低物理骨架对可靠词级时间戳的无差别覆盖。

本次只处理 `AcousticValidator` 及其测试，不改 ASR 路由、VAD 主流程、Global ASR、LLM 合并和字幕导出。

## 2. 当前问题

声学骨架由连续语音区间组成。字幕端点落在两个语音区间之间时，开始端点和结束端点的候选方向不同：

- 开始端点应优先寻找后一个语音区间的起点；
- 结束端点应优先寻找前一个语音区间的终点。

当前通用边界查询会为两种端点返回同一个后续边界，可能把结束时间延长到下一段语音附近，跨过真实静音。

另外，配置中的吸附置信度门控没有在通用声学校验中完整生效，词级时间戳可靠时仍可能被物理端点改写。

## 3. 设计

### 3.1 方向感知的边界查询

新增方向感知查询，返回静音间隙两侧的边界：

- `start`：返回下一个 speech start；
- `end`：返回上一个 speech end。

结束端点只有在候选前一个 speech end 位于当前事件结束时间之前时才允许收缩。后续 speech start 仅作为切尾诊断证据，不作为自动延长目标。

### 3.2 置信度门控

将事件级置信度和词级时间戳可用性作为吸附决策输入：

- 有词级时间戳且事件/边界置信度达到阈值：保留当前 ASR 边界，物理层只报告异常，不主动改写；
- 没有可靠词级时间戳或置信度不足：允许在 `max_snap_distance` 内向合法物理边界吸附；
- 绝对静音和明显物理越界仍可触发保护性修正，但不跨越不连续语音区间。

门控采用兼容式读取：没有 `confidence` 字段的旧事件按低置信度处理，保持现有保护能力。

### 3.3 诊断

报告保留既有计数，并补充每次跳过或修正的原因、原始时间、候选时间、方向和距离，便于区分 ASR 偏移与物理校验偏移。

## 4. 测试

新增或扩展无模型单元测试：

1. 静音间隙中的结束端点选择前一个语音终点；
2. 静音间隙中的开始端点选择后一个语音起点；
3. 后续语音起点不会被用作结束时间的自动延长目标；
4. 高置信度且有词级时间戳的事件不被物理边界覆盖；
5. 低置信度事件仍可完成合法吸附；
6. 报告能够记录跳过原因和修正方向。

## 5. 非目标

- 不改变 `skeleton_mode` 的默认值；
- 不接入 Global ASR；
- 不改变 Silero、ffmpeg 或 BoundaryFusion 算法；
- 不增加多轮 ReASR 或多引擎投票；
- 不调整通用字幕显示时长规则。
