# 全局 ASR、异常窗口与多引擎复核方案

日期：2026-07-31  
状态：设计方案，待实现

## 1. 背景

当前字幕生成在疲劳呻吟、叹气、呼吸声和短促非语义人声上容易产生训练语料幻觉，例如重复输出 `ご視聴ありがとうございました`、`Thank you` 或 `感谢观看`。

样例 `Grow Up Show ～向日葵馬戲團-4min-人声` 中，两份生成字幕都出现了 6 次 `ご視聴ありがとうございました`，人工字幕对应位置没有这些内容。典型异常是 `0.60s + 14 个日文字符`，CPS 为 `23.33`。人工参考字幕同时说明，合理的 `ありがとうございました` 不能仅因为文本相似而全部删除。

现有全局路径还存在一个边界问题：全局 ASR 结果被直接分配到物理字幕箱并参与事件生成。物理字幕箱只能描述声学范围，不能证明其中的文本真实。全局 ASR 的时间戳也不能直接成为最终字幕时间轴。

本方案采用“多来源证据复核”原则：全局 ASR 只提供上下文和冲突证据；默认沿用现有分段和声学模块；只有高风险窗口才调用第二 ASR 引擎 Qwen3-ASR；必要时使用强制对齐和 LLM 语义审查。

## 2. 目标与非目标

### 2.1 目标

- 降低呻吟、叹气、呼吸声和静音段产生的训练语料幻觉。
- 保护真实的极短对白、语气词、同音词和合理重复对白。
- 禁止全局 ASR 直接覆盖最终字幕时间轴。
- 对异常窗口使用上下文重识别，恢复完整文本后按真实词时间重新分段。
- 在主引擎无法判断时，用 Qwen3-ASR 提供异质文本证据。
- 保留可解释的证据来源、模型结果、裁决原因和降级状态。
- 用分层黄金测试集验证幻觉误保留率、真实字幕误删除率和时间轴质量。

### 2.2 非目标

- 不默认对完整音频运行多个 ASR 引擎。
- 不把 CPS、黑名单、LLM 或单个模型结果作为自动删除的唯一依据。
- 不把上下文窗口直接输出为一条字幕。
- 不用强制对齐把错误文本伪装成可靠时间戳。
- 不在本方案中重写现有 VAD、说话人聚类和字幕导出格式。

## 3. 模型与模块职责

```text
分段 ASR       主要字幕候选和默认文本来源
全局 ASR       上下文、漏识别、重复和冲突证据
VAD/FFmpeg/RMS 声学范围、边界和有效能量证据
SED           sigh/breathing/cough/non-speech 等辅助标签
Qwen3-ASR     高风险窗口的异质文本复核
ForcedAligner 通过文本与音频生成次级词级时间证据
LLM           训练语句和上下文语义风险审查
物理时间线    最终时间边界和长静音约束
```

faster-whisper 与 whisper.cpp 都属于 Whisper 体系，可能共享类似的训练语料幻觉。Qwen3-ASR 的作用是增加模型异质性，但必须先通过目标语言和呻吟样例验证其识别质量。Qwen3-ASR 即使输出词级时间，也不能单独覆盖物理时间线。

## 4. 默认处理流程

```text
音频 / 人声轨道
  |
  +--> VAD + FFmpeg + RMS + 物理时间线
  |
  +--> 分段 ASR -------------------------+
  |                                      |
  +--> 全局 ASR（只作证据） -------------+--> 异常评分
                                             |
                                  +----------+----------+
                                  |                     |
                                正常                 中高风险
                                  |                     |
                            保留分段结果       主引擎上下文 Re-ASR
                                                        |
                                             仍冲突/高风险？
                                                        |
                                                  Qwen3-ASR
                                                        |
                                           必要时 SED/ForcedAligner
                                                        |
                                                  LLM 审查
                                                        |
                                                 证据裁决
                                                        |
                                  词级时间 + 声学边界重新分段
                                                        |
                                                  ASS/SRT 输出
```

正常片段不重复调用第二引擎。异常事件应优先按相邻语音事件分组，再生成临时识别窗口。窗口可以包含多句话和停顿，但最终字幕必须按词级结果和物理语音范围拆分。

例如 `02:35.73–02:42.68` 可作为一个上下文窗口识别，但不能输出一条覆盖整个窗口的字幕。

## 5. 异常评分

### 5.1 风险因素

风险评分应同时考虑：

- 短时长和有效字符数；
- CPS；
- 日文、中文和英文训练短语；
- 相距较远窗口中的重复文本；
- 分段 ASR 与全局 ASR 的文本或时间冲突；
- 缺少稳定词级时间戳；
- `no_speech_prob`、`avg_logprob`、压缩率和词置信度；
- VAD/FFmpeg/RMS 的有效语音覆盖率；
- SED 的 `sigh`、`breathing`、`non-speech` 等标签；
- 前后文语义不完整或明显不匹配。

CPS 只能提高风险分数，不能独立触发删除。初始保护条件可以使用 `duration < 0.8s`、`CPS >= 15` 和 `CPS >= 20 且字符数 >= 8`，但正式阈值应按语言、引擎和音频场景动态校准。

### 5.2 动态基线

不要直接使用均值加两倍标准差，因为幻觉异常值会污染均值和标准差。建议按语言、引擎和场景使用中位数、MAD 或分位数建立基线，并保留绝对保护线。

重复检测还应结合：

- Unicode、标点和假名归一化；
- 字符级编辑距离；
- 可用时的音素相似度；
- 时间距离和场景距离；
- 是否为歌曲副歌、演讲强调或真实对话重复。

合理重复不能仅凭文本重复直接删除。

### 5.3 风险等级

- `low`：保留分段 ASR 结果；
- `medium`：调用主引擎上下文 Re-ASR；
- `high`：主引擎复核后仍冲突时调用 Qwen3-ASR；
- `critical`：训练短语、无词级证据、SED 非语义标签和模型冲突同时出现，进入强复核或人工复核。

## 6. 上下文 Re-ASR

异常片段是复核目标，不是新的字幕边界。建议初始参数：

- 左右基础上下文：`0.8s`；
- 同一窗口最大范围：`8-12s`；
- 最大识别窗口：`15s`；
- 已确定的目标语言，例如日语使用 `ja`；
- 开启词级时间戳；
- 保留真实静音和说话人边界。

流程：

1. 将异常事件及相邻语音事件组成临时窗口；
2. 使用主 ASR 重新识别窗口；
3. 对输出词与原分段事件、全局词流进行对齐；
4. 恢复多句文本时按词级时间拆分；
5. 不使用窗口起止时间生成字幕；
6. 不允许字幕覆盖长静音。

如果窗口结果恢复出 `もう一杯ください`，应按实际词时间替换原来的 `ください`，而不是继续使用原始短片段结果。

## 7. Qwen3-ASR 第二引擎

Qwen3-ASR 只处理高风险窗口，不处理完整音频。

触发条件包括：

- 主引擎 Re-ASR 后仍与全局结果冲突；
- 疑似训练短语；
- 多个不连续位置出现相同短语；
- 音频有能量但疑似呻吟、叹气或呼吸声；
- 主结果缺少可靠词级证据；
- 结果会导致字幕删除、替换或多句拆分。

多模型不采用简单多数投票。应综合比较文本、音素/字符相似度、词级证据、声学范围、置信度和上下文完整性。

## 8. ForcedAligner 对齐

如果 Qwen3-ASR 只输出纯文本，可以使用支持目标语言的 MFA 或其他 ForcedAligner 生成次级词级时间。

处理约束：

1. Qwen 文本必须先通过基本语义和声学检查；
2. 未通过检查的训练短语不能直接强制对齐；
3. 强制对齐结果标记为 `qwen_forced_alignment`；
4. 原生词级时间的优先级高于强制对齐时间；
5. 强制对齐只能参与 `split` 和边界候选，不能单独决定 `keep`；
6. 对齐失败时保留文本冲突诊断，不伪造时间戳。

强制对齐可以改善时间定位，但不能证明文本一定真实。

## 9. 声学边界仲裁

词级时间与声学边界冲突时使用容差，不进行立即硬裁切。

建议初始容差为 `50-100ms`：

- 超出边界但在容差内：以词级时间为主并做微调；
- 超出容差：重新检查局部音频和相邻词；
- 仍无法确认：进入 `unresolved`；
- 不强行截断完整词；
- 不允许最终字幕覆盖明显长静音。

最终边界顺序为：

```text
词级时间观察值
  -> 容差修正
  -> 声学合法范围约束
  -> 物理时间线校验
  -> 最终显示边界
```

## 10. SED 辅助检测

可以在高风险窗口并行调用 YAMNet、AST 或其他轻量级 SED，识别 `sigh`、`breathing`、`cough`、`vocalization` 和 `non-speech`。

SED 不是独立删除器。只有当 SED 非语义标签、ASR 高风险、词级证据不足，并且主引擎或 Qwen3-ASR 不支持有效对白时，才允许提高到高置信度 `drop`。

## 11. LLM 语义审查

LLM 只检查语义和训练语料风险，不生成时间戳，也不能单独删除字幕。

输入：

- 当前字幕和前后文；
- 主 ASR、全局 ASR 和 Qwen3-ASR 文本；
- 声学诊断和词级证据；
- CPS、重复和训练短语风险。

输出使用结构化 JSON：

```json
{
  "class": "likely_training_phrase",
  "confidence": 0.91,
  "action": "review",
  "evidence_codes": [
    "repeated_phrase",
    "no_stable_word_evidence",
    "context_mismatch"
  ],
  "short_reason": "短语在多个无对白位置重复出现"
}
```

不要求保存完整 chain-of-thought，只保存证据代码和简短原因，避免将模型推理内容混入诊断和缓存。

## 12. 最终裁决

裁决优先级：

1. 是否存在有效语音和声学边界；
2. 是否有稳定的原生词级时间戳；
3. 分段 ASR、上下文 ASR、全局 ASR 和 Qwen3-ASR 是否一致；
4. 文本是否与前后文构成合理语句；
5. 是否为训练语句或重复幻觉；
6. LLM 语义风险判断；
7. CPS 仅作为辅助因素。

最终动作：

- `keep`：证据一致，保留文本并校正时间；
- `replace`：局部复核结果更可靠；
- `split`：上下文识别恢复多句对白；
- `drop`：无有效语音和文本证据的幻觉；
- `unresolved`：证据冲突，等待人工复核。

Qwen3-ASR、ForcedAligner、LLM 和黑名单都不能单独触发 `drop`。

## 13. 中间数据、缓存与诊断

每个候选结果必须保留：

- `source`；
- `engine`；
- `window_id`；
- `segment_id`；
- `word_ids`；
- `confidence`；
- `no_speech_prob`；
- `avg_logprob`；
- `compression_ratio`；
- `alignment_type`；
- `trigger_reasons`；
- `decision`；
- `decision_reason`。

缓存键必须区分全局 ASR、分段 ASR、上下文 Re-ASR、Qwen3-ASR、ForcedAligner 和 LLM，并包含模型、语言、窗口范围、词级时间开关及策略版本。缺失置信度时不能默认填充为高置信度。

## 14. 分层回归测试集

黄金测试集至少包含：

- 长静音训练短语；
- 疲劳呻吟；
- 短小叹气；
- 呼吸声；
- 极短但真实的对白；
- 连读和吞音；
- VAD 过度切分；
- 背景音乐干扰；
- 合理重复对白；
- 歌曲副歌；
- 多语言混合。

每次模型、阈值或裁决策略变更后，记录：

- 幻觉字幕 precision、recall、F1；
- 真实字幕误删除率；
- 有效对白召回率；
- 字幕时间 MAE；
- 字幕事件时间 IoU；
- 无语音字幕总时长；
- Qwen3-ASR 调用率；
- ForcedAligner 成功率；
- LLM 调用率；
- `unresolved` 比例。

## 15. 实施阶段

### 阶段一：证据和异常评分

增加日文训练短语、Unicode 字符统计、动态 CPS 基线、重复和跨来源冲突评分。此阶段只运行 shadow mode，不改变字幕输出。

### 阶段二：全局结果降权

禁止全局词流直接生成最终字幕时间轴。将全局结果改为辅助证据，并保留来源、词级时间和模型指标。

### 阶段三：上下文 Re-ASR

实现异常事件分组、临时窗口调度、按词级时间重新分段和物理静音约束。

### 阶段四：Qwen3-ASR 复核

接入 Qwen3-ASR 适配器，仅处理高风险窗口，增加模型冲突和降级诊断。

### 阶段五：对齐、SED 与 LLM

在验证 Qwen 文本质量后接入 ForcedAligner；按需增加 SED 和结构化 LLM 语义审查。

### 阶段六：正式启用

完成缓存版本升级、黄金测试集、人工复核队列和质量门禁后，再启用自动 `replace` 与 `drop`。

## 16. 验收标准

- 全局 ASR 的时间戳不会直接成为最终字幕时间轴。
- 正常字幕继续沿用现有分段和声学边界逻辑。
- 高风险窗口可以通过主引擎上下文 Re-ASR 修复。
- Qwen3-ASR 只在高风险窗口调用。
- Qwen 纯文本可以在通过文本检查后使用 ForcedAligner 补充时间证据。
- ForcedAligner 不会把未经验证的幻觉文本提升为可靠字幕。
- LLM 只能输出结构化风险判断，不能单独删除或生成时间。
- `ご視聴ありがとうございました` 等无声训练短语不会进入最终字幕。
- `はぁ`、`え?`、`ください` 等真实短片段不会因 CPS 单项规则被批量删除。
- 每条最终字幕都能追溯到词级、声学或明确的降级证据。
- 模型冲突时不会采用简单多数投票强行生成字幕。
