# 影视级字幕全链路质量优化设计

**日期：** 2026-07-27

**状态：** 设计已确认，实施计划已建立

**适用范围：** 中英文、单人/多人语音、少量真实重叠说话的离线字幕生产

## 1. 背景

2026-07-27 的 WebUI 实测完成了 `test/` 目录下 8 段音频的真实识别。其中 6 个有人工字幕的样本显示：

- 文本可以完全正确，但多个自然句仍被合并为一条字幕。
- 导出事件的起止平均误差从几十毫秒到数百毫秒不等，且存在尾部延长。
- WebUI 预览与导出 SRT 使用了不同阶段的事件，导致数量和去重结果不一致。
- 导出结果存在非真实的相邻字幕重叠，而页面的声学健康度仍可显示 100%。
- 现有严格分段、物理字幕仓和最终校验代码已具备部分能力，但物理归属数据没有完整贯穿 Pipeline、LLM、WebUI 和导出。

本设计不用 ASR 时间戳硬填整个 VAD 区间，也不让 LLM 猜测数值时间。其核心是保留现有 VAD/FFmpeg 物理时间轴，将其作为不可变的声学证据和候选锚点，再由受约束的语义阶段完成断句与组合。

## 2. 产品目标

1. 字幕内容必须覆盖可听人声，不得切头、切尾、重复灌词或凭语义补写无声学依据的内容。
2. 物理时间轴可追溯、可校验，显示时间轴可为阅读体验做有界调整。
3. LLM 优化语义断句、标点和 UNKNOWN 说话人归属，但不拥有物理时间轴。
4. 预览、API、SRT/ASS 导出和质量报告使用同一份最终事件。
5. 在已配置联网 LLM 时优先质量模式；断网或 LLM 不可用时仍能通过本地规则完成可验证的字幕产出。

## 3. 非目标

- 首版不对复杂抢话、大量重叠语音或背景多轨对白承诺完全分离。
- 不用 LLM 直接生成或改写浮点时间戳。
- 不以扩大 VAD 或 PhysicalClip 边界的方式改善指标。
- 不要求自动字幕逐字复制人工成片字幕的删减。可听语气词、短词和重复表达应优先保留。

## 4. 已确认的设计决策

| 主题 | 决策 |
|---|---|
| 部署 | 离线主链路 + 可选联网质量增强；已配置 LLM 时优先使用 |
| 时间轴 | 保留不可变物理时间和可调整显示时间两套边界 |
| 场景 | 中英文、单人/多人、少量真实重叠说话 |
| 性能 | 质量优先，整体耗时目标不超过约 2 倍音频时长 |
| 评测 | 成片人工字幕 + 词级声学金标准双基准 |
| 静音 | 自适应三级阈值，而非单一固定值 |
| 边界仲裁 | 先用硬约束过滤，再对校准后的多源证据评分；不采用固定信号优先级 |
| 重叠对白 | 内部保留独立 speaker 轨道；SRT 合成双行，ASS 可分别定位 |

## 5. 总体架构

统一中间表示为：

```text
PhysicalTimeline
       + LocalNoiseProfile
       + GlobalTranscript / GlobalSpeakerTimeline
                         |
                         v
BoundaryArbiter -> WordToken -> PhysicalFragment -> SemanticCue -> DisplayCue
```

### 5.1 不可变声学证据层

复用当前代码中的 `PhysicalTimeline`、`PhysicalClip`、`SpeechEvidenceSpan` 和 `PhysicalSubtitleBin`，不建立竞争性的第二套物理时间轴。

以下输入保留原始起止时间、来源、置信度和证据 ID：

- FFmpeg coarse speech 与 acoustic skeleton
- Silero VAD 人声区间
- RMS 能量边界
- boundary fusion 边界
- 宏观 PhysicalClip 及其绝对时间坐标

FFmpeg 回答“有声/静音”，Silero VAD 回答“是否人声”。前者是高精度声学标尺，但可能把音乐、撞击声或呼吸当成人声，因此不能单独决定字幕归属。

### 5.2 WordToken

`WordToken` 是最小语音证据单元，它需要表达：

- 稳定 `word_id`、原始文本和规范化文本
- ASR 原始时间与受约束对齐后的物理时间
- ASR/VAD/FFmpeg/RMS 的证据引用和置信度
- speaker 标签、speaker 是否已确认、是否重叠
- `physical_clip_id`、物理字幕仓归属及对齐诊断

对齐器将 ASR 时间视为观测值，将 VAD/FFmpeg/RMS 视为边界候选与合法范围。它不得把最后一个词强制延长到整个 VAD 段末尾。

原始声学证据在任务开始后始终不可变。WordToken 的对齐物理时间由仲裁阶段计算，一旦进入语义阶段便冻结；后续 LLM 和显示映射不得反向修改它。

### 5.3 PhysicalFragment

`PhysicalFragment` 是连续的短句候选单元，包含有序 `word_ids`、物理跨度、候选 speaker、停顿类型和证据引用。

分片使用自适应三级停顿：

- 微停顿：初始约 120-250ms，仅作候选切点。
- 句间停顿：初始约 250-500ms，提高切分权重。
- 长停顿：初始约 500ms 及以上，作为不可跨越硬边界。

初始值不是全局常量。系统应按当前说话人的语速与停顿分布校准，并受最小/最大阈值夹持。明确 speaker 变化与 PhysicalClip 边界始终是硬分隔。

### 5.4 SemanticCue

`SemanticCue` 只表达语义组织结果：有序词/片段 ID、标点、规范文本、speaker 决策、修订来源和置信度。它不接受 LLM 生成的数值时间。

错字规范化以“绑定原始 word ID 的文本覆盖层”表达，不创建伪造的无来源词。若修订改变词数或补入缺失口语，必须先经过局部再识别并产生新的声学词证据。

### 5.5 DisplayCue

`DisplayCue` 是唯一可供 WebUI、API 和导出器消费的最终事件。每条事件同时保存：

- `physical_start/end`：首尾词及声学证据决定的不可变时间。
- `display_start/end`：在不跨越硬边界、不覆盖下一说话人、不制造假重叠的前提下，向附近静音边界吸附并满足阅读停留时间。

### 5.6 BoundaryArbiter

`BoundaryArbiter` 是唯一有权生成或接受词级物理边界的组件。它复用 `PhysicalTimeline` 中的证据，不创建第二套时间轴，也不允许任何单一信号拥有永久的一票决定权。

候选边界至少记录时间、起点/终点方向、来源、原始置信度、局部噪声区间和 evidence ID。仲裁结果使用结构化对象而不是无诊断信息的布尔值：

```text
BoundaryDecision(
    accepted,
    boundary_time,
    boundary_type,
    confidence,
    evidence_ids,
    reason_codes,
)
```

仲裁分两层：

1. **硬约束过滤**：时间有限且单调，位于所属 PhysicalSubtitleBin/PhysicalClip 的合法范围内，不跨硬边界，不截断已确认人声，不覆盖下一说话人的确认人声。
2. **候选评分**：对经过归一化和后端校准的 ASR 置信度、RMS 梯度/谷底、VAD 人声概率、FFmpeg 静音区间、来源一致性和局部噪声状态评分，再使用确定性规则解决同分。

起点和终点采用不同损失函数：起点优先避免吞掉辅音、气音和弱起声，终点优先避免切掉渐弱尾音。连续约 200-400ms 的低能静音是强终点候选，但不是所有字幕换条的必要条件；连续语音可在受证据支持的词间边界换条，已确认 speaker 变化、PhysicalClip 边界和真实重叠轨道边界仍可直接形成硬分隔。

搜索窗口按置信度等级调整。高置信度词使用较小窗口，初始可约为 `±200ms`；低置信度词使用较大窗口，初始可约为 `±500ms`。窗口始终被相邻词、PhysicalSubtitleBin、PhysicalClip 和 speaker 硬边界夹持。置信度等级必须按 ASR 后端在评测集上校准；`0.9`、`0.6` 或某一固定物理权重只能作为实验初值，不能作为跨后端全局常量。

所有 `physical_start/end` 在冻结前必须取得被接受的 `BoundaryDecision` 或明确的 `timing_degraded` 降级决策。`display_start/end` 由最终显示校验器验证覆盖关系和硬边界约束，不要求与物理边界使用同一种候选类型。

## 6. 数据流

### 6.1 全局声学分析

音频先统一到绝对时间坐标。FFmpeg 声学骨架、Silero VAD、RMS、边界融合和宏观 PhysicalClip 只运行或复用一次，结果写入 `PhysicalTimeline`。

同一阶段按滚动窗口计算稳健的局部底噪统计，形成 `LocalNoiseProfile`。系统使用分位数、MAD 等抗异常统计检测底噪突变，并通过滞回、最小稳定区间及上下限夹持避免阈值来回抖动。稳定噪声区间可采用各自的 FFmpeg `silencedetect` 阈值和最短静音参数，或由局部 RMS/VAD 直接补充候选；不能把单次固定阈值的 FFmpeg 调用描述成连续动态阈值。

噪声模型、分段阈值、变点和回退原因作为不可变证据写入物理阶段缓存。若局部噪声估计不可靠，则回退到配置阈值并降低相关候选置信度，而不是扩大 PhysicalClip 或把整段音频判为语音。

### 6.2 词流与说话人

ASR 产生全局词级时间戳，说话人识别并行产生 speaker turns。受约束对齐器给每个词分配物理字幕仓、对齐边界、speaker 和置信度。

无法完全放入任一物理字幕仓的跨仓词必须保留整词并记录诊断，不能裁掉一半文字。

说话人异常检测以全局 diarization turn 或 speaker embedding 距离为主要依据。RMS 均值突变只能产生 `SPK_CHANGE_CANDIDATE` 弱信号，不能单独强制换人；距离阈值也必须按模型和场景校准。MFCC/F0 短时包络可在 embedding 不可用时补强，只有基线样本足以稳定估计协方差时才使用马氏距离。

候选经过 diarization change point 或多源声学一致性确认后才升级为 speaker 硬边界。LLM 只能在硬边界限定的 `UNKNOWN` 范围内补全 speaker ID，不能跨过已确认边界合并片段，也不能覆盖已确认标签。

### 6.3 动态物理分片

分片器依次使用 PhysicalClip 边界、speaker 变化、真实重叠、停顿分级和显示长度候选创建 `PhysicalFragment`。它不做语义改写。

### 6.4 LLM 语义滑窗

滑窗向 LLM 发送：

- fragment ID 和有序 word ID
- 文本、语言、候选 speaker 及其置信度
- 停顿等级、物理硬边界标记与重叠标记
- 前后有限语义上下文

LLM 只能返回符合 schema 的操作：

- 在合法候选间合并或拆分
- 添加标点并规范明显错字
- 仅对 `UNKNOWN` 推断 speaker
- 标记疑似漏词、错词或边界冲突以请求复核

LLM 不能：

- 返回可直接采信的 start/end 浮点数
- 跨越长静音、PhysicalClip 或已确认 speaker 边界
- 更改已确认的 speaker
- 生成无来源词 ID 的正式文本

窗口重叠部分通过稳定 ID 去重。窗口大小受片段数、token 预算和硬边界共同限制，不允许为获得更长语义上下文而跨越物理硬边界。

### 6.5 疑难片段复核

LLM 识别到疑似漏词或低置信度错词时，只生成复核请求。系统对局部音频使用上下文提示、备用 ASR 或强制对齐进行再识别。只有新结果取得声学证据和足够置信度后才能替换正式文本。

### 6.6 受限投影与回投状态机

LLM 返回语义分组后，后端只在该组首尾词附近、仲裁器给出的合法候选集合中投影边界。每个语义组经过以下有限状态：

```text
PROPOSED -> PROJECTED -> ACCEPTED
                      -> MERGED
                      -> ONE_REPAIR -> PROJECTED
                      -> FALLBACK
```

- 找到合法候选时进入 `ACCEPTED` 并冻结物理边界。
- 窗口内没有合法候选时，确定性地与相邻兼容语义组合并；不得在非静音区伪造平滑切点。
- 合并仍造成长度、speaker 或硬边界冲突时，最多向 LLM 发起一次受限修复。修复请求只暴露可重组的 ID 和合法候选 ID，LLM 不能发明新切点。
- 修复仍失败时回退到通过验证的 PhysicalFragment 字幕并记录原因，不允许循环调用 LLM。

### 6.7 反向映射与显示时间

后端根据 LLM 返回的有序 ID 取首尾词物理跨度，再在合法 PhysicalSubtitleBin 内向最近的 VAD/FFmpeg 静音边界吸附。

显示时间可适度提前或延后，但必须同时满足：

1. 不截断已确认的首尾人声。
2. 不越过物理硬边界。
3. 不覆盖下一说话人的人声起点。
4. 不制造无声学依据的相邻事件重叠。
5. 在上述约束内尽可能满足语言 profile 的阅读速度与停留时间。

### 6.8 最终校验与单一出口

最终校验器统一检查：

- 排序与编号
- 来源词和证据完整性
- 硬边界、PhysicalClip 和 speaker 归属
- 重复词、遗漏词和无来源文本
- 非真实重叠及负时长
- 行数、字符数、CPS 和显示时长

校验通过的 `DisplayCue` 列表是字幕唯一出口。Pipeline 不得向 WebUI 返回构建前的事件。

## 7. 重叠说话与导出

内部对少量真实重叠说话保留独立 speaker 轨道和物理跨度。

- SRT：同期短对白合成一个双行 cue，使用可配置说话人前缀。
- ASS：可为不同 speaker 使用独立事件和位置。
- 非真实重叠：由最终校验器裁剪或回退，不允许通过导出层掩盖。

当重叠分离置信度不足时，应保留冲突诊断或输出 `UNKNOWN`，不进行虚假串行化，也不删除可听次要对白。

## 8. LLM 运行策略

### 8.1 路由

1. 已配置且可访问联网 LLM：优先质量模型。
2. 联网 LLM 不可用或单窗口失败：局部回退到离线规则，其他窗口继续使用 LLM。
3. 未配置 LLM：整条任务使用本地停顿、标点、长度和 speaker 约束断句。

### 8.2 输出验证

LLM 输出必须通过结构化 schema 与业务不变量验证。以下情况拒绝对应操作：

- 未知词/片段 ID
- ID 重复、丢失或顺序逆转
- 跨硬边界或跨已确认 speaker 合并
- 修改已确认 speaker
- 没有证据 ID 的新增正式文本
- 无法解析或超出窗口权限的时间信息

单窗口结构失败时允许有限重试。重试后仍失败则回退本地规则，不因一个窗口中止整个音频。

## 9. 异常处理与质量降级

| 异常 | 处理 |
|---|---|
| LLM 不可用 | 单窗口本地降级，保留其他窗口结果 |
| LLM 越权 | 拒绝操作，不接受部分污染结果 |
| 词时间缺失/漂移 | 局部强制对齐或备用 ASR；失败后降级到片段时间并标记 `timing_degraded` |
| 疑似漏词/错词 | 只触发局部再识别，无新声学证据时不补写 |
| FFmpeg/VAD 冲突 | 结合人声置信度和局部能量仲裁，保留全部原始证据 |
| 局部噪声模型不稳定 | 回退配置阈值、降低候选置信度并记录 noise-profile warning |
| 语义边界无合法投影 | 确定性合并；一次受限修复后仍失败则回退 PhysicalFragment |
| RMS 与 speaker 特征冲突 | RMS 只保留为异常提示，以 diarization/embedding 或多源一致性为准 |
| speaker 不确定 | 保留 `UNKNOWN`，不为了格式整齐强制归类 |
| 最终校验失败 | 回退到通过验证的 PhysicalFragment 字幕；仍越界时标记需复核，不伪装成功 |

系统为低置信度窗口设置有限的局部 ASR 和 LLM 复核次数。不允许无限重试。

## 10. 缓存与可观测性

声学、局部噪声、ASR、speaker、边界仲裁、LLM 和最终映射分阶段缓存，每层带配置指纹和 schema 版本。

- 修改 LLM prompt 只使 LLM 及下游缓存失效。
- 修改 VAD/FFmpeg/RMS 参数使声学及所有下游缓存失效。
- 修改导出格式只需重新生成显示与文件。

每个自动操作记录阶段、输入 ID、输出 ID、规则/模型、置信度和原因。边界诊断还需记录搜索窗口、被硬约束拒绝的候选、噪声区间、最终 evidence IDs 和状态机终态。质量报告必须分开展示“声学边界健康度”、“语义断句健康度”、“说话人健康度”和“最终结构健康度”，不再用单一 100% 值掩盖结构错误。

## 11. 全局不变量

1. 每条字幕必须能反查到词或物理片段。
2. 每个词必须有合法物理归属或明确对齐警告。
3. LLM 决定语义组织，不拥有物理时间轴。
4. 已确认 speaker 不可被 LLM 篡改。
5. 不得跨越 PhysicalClip、长静音或明确 speaker 硬边界。
6. 只有真实重叠语音允许重叠字幕。
7. 预览、API、SRT/ASS 和报告使用同一份通过最终校验的事件。
8. 所有自动修订保存来源、置信度和原因，可回滚、可对比。
9. 每个冻结的物理起止点必须来自被接受的 BoundaryDecision 或明确的 timing-degraded 降级决策。
10. 静音是强边界证据但不是连续语音换条的必要条件；系统不得为满足静音规则吞掉语义换条或 speaker 硬边界。
11. RMS 音量差不能单独创建 speaker 硬边界，LLM 修复不能创建物理候选。

## 12. 评测基准

### 12.1 双基准

1. **词级声学金标准**：从测试集抽取中英文、单人、多人、快慢语速和少量重叠片段，人工标注词级首尾发声与 speaker。
2. **成片字幕参考**：现有人工 SRT/ASS 用于评估文本、断句、显示时长和排版，不直接作为物理边界真值。

### 12.2 首版验收门槛

| 维度 | 验收目标 |
|---|---|
| 物理边界 | 中位绝对误差 `<=80ms`，P95 `<=160ms` |
| 切头/切尾 | 超过 `80ms` 的可听语音截断率 `<=0.5%` |
| 来源完整性 | `100%` 字幕可回溯至词 ID 和物理证据 |
| 结构正确性 | 跨硬边界、跨已确认 speaker、重复灌词、非真实重叠均为 `0` |
| 文本准确率 | 清晰语音中文 CER/英文 WER `<=5%`；复杂多人场景 `<=10%` |
| 无依据补写 | 正式字幕中的无声学来源新增内容为 `0` |
| speaker | 已确认标签保持率 `100%`；UNKNOWN 推断准确率目标 `>=95%` |
| 排版 | 最多两行，字符数、CPS、最短/最长显示时长按中英文 profile 配置 |
| 性能 | 质量模式整体耗时不超过约 `2x` 音频时长 |

物理边界误差必须相对词级发声真值计算，不得相对人工成片字幕的显示延展时间计算。

### 12.3 测试层次

1. **单元与属性测试**：验证时间不变量、ID 来源、硬边界、speaker 权限和缓存指纹。
2. **合成音频测试**：精确验证静音、连续语音换条、短词、气音/弱起声、渐弱尾音、底噪突变、非人声高能事件、音量变化但 speaker 不变、无静音 speaker 切换和重叠对白。
3. **双基准回归**：比较改造前后 CER/WER、边界分位数、断句、speaker 和排版。
4. **浏览器端到端**：验证预览、API、SRT/ASS 下载和质量报告使用完全一致的最终事件。

当前 8 个浏览器实测音频作为初始回归集；6 个带人工字幕的样本继续评估文本与显示效果。补充词级声学金标准后，才将 80/160ms 边界指标作为发布门禁。

## 13. 分阶段交付边界

详细步骤由后续实施计划确定，但实施必须保持以下依赖顺序：

1. 先完善核心事件数据契约和物理证据传递，接通现有物理时间轴与局部噪声模型。
2. 再统一构建、最终校验、WebUI/API 与导出出口。
3. 然后实现结构化边界仲裁、受约束词对齐、自适应分片与双时间轴。
4. 在确定性主链路通过不变量测试后接入 LLM 滑窗和局部再识别。
5. 最后加入重叠对白导出、双基准门禁和浏览器回归。

每个阶段都必须产生可运行、可回归的主链路，不能以“后续阶段会修复”为理由放行跨物理边界、丢失词或预览/导出不一致。
