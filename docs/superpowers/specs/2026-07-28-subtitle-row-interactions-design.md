# 字幕时间轴行级播放与双击编辑设计

日期：2026-07-28

## 目标

优化字幕时间轴交互：单击字幕行任意位置播放对应时间段，双击文本列进入编辑，同时避免浏览器将字幕编辑输入误判为密码保存字段。

## 交互设计

- 单击字幕行的任意单元格，播放该行字幕的 `start` 到 `end` 区间。
- 单击事件延迟约 220ms 执行，以便识别双击。
- 双击原文、优化后或最终版本文本列时，取消待执行的单击播放并进入现有编辑流程。
- 播放按钮继续立即播放，并阻止事件冒泡，避免重复触发整行播放。
- 在编辑输入框聚焦期间，点击输入框不触发行播放。
- 当前播放行继续使用现有高亮和播放按钮状态，不增加新的播放状态模型。

## 实现边界

前端改动集中在 `vocal_subtitle/webui/static/index.html`：

1. 为字幕行增加单击/双击事件调度。
2. 抽取或复用行播放调用，保持 `playSegment` 的音频加载、回退和清理逻辑不变。
3. 为动态字幕编辑输入补充 `autocomplete="off"` 等非凭据字段语义。
4. 为页面中的 API Key 和 HF Token 输入补充密码管理器可识别的非登录凭据语义，避免编辑字幕时触发保存密码提示；不改变值的保存方式和请求行为。

## 数据流与异常处理

字幕行通过闭包持有当前字幕事件，播放仍调用既有 `App.ui.playSegment(event, button)`。没有任务 ID 时沿用现有提示；音频加载失败、分离人声回退和播放清理逻辑不变。双击检测只负责取消尚未执行的播放定时器，不取消已经开始的播放。

## 验证

- 静态检查：页面脚本可解析，所有新增选择器和事件绑定均存在。
- 交互检查：单击行的序号、时间、说话人、文本等区域均能触发对应片段播放；双击三个文本列只进入编辑，不触发播放；播放按钮不重复播放。
- 浏览器检查：编辑字幕时不再出现密码保存提示；API Key/HF Token 输入仍可正常录入和使用。
- 回归检查：字幕保存、播放按钮、音频失败回退、视图切换均保持原行为。
