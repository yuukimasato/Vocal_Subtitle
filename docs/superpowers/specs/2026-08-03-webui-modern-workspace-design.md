# WebUI 现代化工作台设计

日期：2026-08-03  
状态：已确认，待实施

## 1. 目标与范围

本阶段针对现有静态 HTML/CSS/原生 JavaScript WebUI 做现代化工作台收口，重点改善布局、视觉层级、响应式体验和跨工作区的一致性。现有 FastAPI 路由、请求响应字段、任务历史 schema、旧 DOM id、`App` 方法和字幕编辑业务逻辑保持兼容。

本阶段不改变 ASR 召回、引擎路由、字幕算法、质量阈值、黄金集门禁、任务持久化协议或发布结论。只有在组件化所必需时，才进行小范围前端模块整理。

## 2. 设计方向

采用渐进式原生前端组件化，不引入 React、Vite 或新的构建链。整体使用深色专业工作台风格：石墨背景、分层面板、靛青主色，绿色/橙色/红色分别表达通过、降级和失败。

视觉系统集中使用 CSS 设计 token 管理颜色、间距、圆角、阴影、字体和交互状态，避免各工作区继续使用互相冲突的局部样式。面板、工具栏、状态徽章、统计卡片、空状态、加载状态和错误状态使用统一表现。

## 3. 页面与组件布局

### 3.1 全局壳层

- 顶部保留品牌、工作区导航和设备状态。
- 导航支持 `process`、`review`、`feedback`、`history`、`quality` 五个 hash 工作区。
- 当前工作区、当前任务和运行状态具有明确的视觉层级。
- 桌面端使用宽屏工作台容器；移动端导航可横向滚动，内容区自动纵向排列。

### 3.2 处理工作区

桌面端采用三段式工作台：

1. 左侧：文件上传、场景模板、高级设置和运行入口；
2. 中间：处理进度、字幕结果、声学校验和导出；
3. 右侧：当前任务摘要、质量状态、阶段信息和快速操作。

窄屏时按“文件与运行 → 进度 → 结果 → 摘要”的顺序排列。上传、开始处理、取消、导出等主要操作保持高可见性。

### 3.3 字幕审核工作区

以时间轴编辑为中心：顶部为任务选择和音频控制，中间为可滚动字幕表格，右侧为选中行检查器与批量操作。当前播放行、未保存修改和质量提示必须可见；小屏幕将检查器移动到表格前后合适位置，不产生横向页面溢出。

### 3.4 反馈、历史与质量工作区

三个工作区共享页面标题、筛选工具栏、面板头部、状态徽章、空状态、加载状态和错误状态。

- 反馈工作区：修订来源、差异预览、学习确认、健康度和审核队列分区展示，预览和写入保持两个明确动作。
- 历史工作区：任务列表与详情双栏展示，支持筛选、分页、审核入口、质量报告入口和显式删除。
- 质量工作区：先展示任务状态、质量状态、生产路径和运行标识，再展示阶段/引擎、质量/声学、降级/错误、证据决策投影和产物信息。

## 4. 数据与兼容边界

前端继续通过现有 API client 访问服务端，不在新组件中复制字幕编辑、反馈学习、任务历史或报告归一化规则。新视觉组件只消费已有共享状态与 API 返回值。

保留旧处理页所依赖的 DOM id、全局 `App` 方法、工作区 hash 和服务端路由。新增样式和结构优先通过兼容包装层接入，避免破坏已有测试与浏览器自动化入口。

## 5. 错误与响应式行为

- 加载时显示明确的骨架/加载状态，不显示空白区域。
- 无任务、无报告、无反馈数据时显示可操作的空状态。
- API 失败时显示可重试错误，并保留用户已有输入或预览结果。
- 降级完成与完全成功分开显示，使用橙色状态而不是绿色成功状态。
- 所有用户可控文本进行 HTML 转义；长文件名、任务 ID、错误信息和 JSON 诊断允许换行。
- 断点下不出现页面级横向滚动，表格内部允许独立滚动。

## 6. 验收标准

- 五个 hash 工作区可独立进入，刷新后保留当前视图。
- 旧处理流程、旧 DOM id、旧 `App` 方法和现有 API 路由继续可用。
- 上传、运行、进度、字幕编辑、批量操作、反馈学习、历史查询和质量报告无功能回归。
- 桌面端信息层级清晰，移动端主要页面在 390px 宽度下无明显重叠或页面横向溢出。
- JavaScript 语法检查、现有 Python 测试、`git diff --check` 和浏览器 smoke 通过。
- 不把无模型浏览器 smoke 结果解释为真实模型、GPU、长音频、外部 LLM 或黄金集发布验收。

## 7. 实施顺序

1. 建立实施基线并记录当前测试、脚本和浏览器状态。
2. 收敛 CSS token、全局壳层、面板和状态组件样式。
3. 调整处理工作区为响应式三段式布局，同时保留旧入口。
4. 调整审核、反馈、历史和质量工作区的统一布局与交互状态。
5. 补齐必要的前端公共辅助函数和组件边界，不迁移后端业务规则。
6. 执行语法检查、定向测试、全量测试和桌面/移动浏览器 smoke，修复回归。
