# LLM 字幕差异高亮设计

## 目标

在字幕时间轴的“LLM 优化”列中，让用户快速识别 LLM 修改过的内容：未修改文本使用浅色，新增或替换后的文本使用深琥珀色。最终版本当前使用绿色，因此差异高亮不使用绿色，避免视觉混淆。

## 范围

- 仅调整前端时间轴的差异渲染和颜色样式。
- 保留现有 ASR、LLM、最终版本三列结构及双击编辑行为。
- LLM 删除的原文不在 LLM 列中显示删除线或残留文本，直接隐藏。
- 没有 LLM 文本时继续保持空白。
- 所有字幕内容继续经过 HTML 转义。

## 实现方案

复用现有的 LCS token 差异算法。算法以 CJK 字符、拉丁单词、空白和标点作为 token：出现在 ASR 与 LLM 文本共同子序列中的 token 视为未修改，其他出现在 LLM 文本中的 token 视为新增或替换后的内容。删除的 token 不会进入 LLM 输出，因此自然隐藏。

样式上保留未修改文本的浅色层级，调整现有 `.diff-added` 为深琥珀文字和低透明度琥珀背景。高亮使用粗体和小圆角增强扫描性，但不改变行高或表格布局。

## 交互与兼容性

- 修改高亮仅影响展示，不改变事件的 `asr_text`、`llm_text` 或 `text` 数据。
- 点击行、播放、双击编辑和最终版本格式切换保持现状。
- 空文本、相同文本、中文、英文、标点和 HTML 特殊字符都必须安全渲染。

## 验证

- 使用现有 WebUI 页面检查修改后的颜色与最终版本绿色之间有足够区分度。
- 增加或更新前端差异渲染测试，覆盖：相同文本、插入/替换文本、删除文本不显示、HTML 特殊字符转义。
- 运行相关 WebUI 测试、编译检查和 `git diff --check`。
