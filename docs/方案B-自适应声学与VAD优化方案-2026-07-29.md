# 方案 B：自适应声学与 VAD 优化方案

**日期**：2026-07-29
**状态**：后续方案，当前不实施
**前置条件**：方案 A 完成，并有稳定的 global/segmented 真实音频基准

## 1. 目标

在方案 A 提供全局词级时间和物理 provenance 后，建立“噪声画像 → 多源声学证据 → ASR 置信度 → 局部恢复”的闭环，改善产品评测、演讲、影视对白、户外录音和音乐现场中的漏检、误检和边界漂移。

本方案不把任何单一阈值视为通用答案，所有参数必须通过真实素材消融验证。

## 2. 当前问题边界

现有 Pipeline 已计算 chunk 级噪声画像，但主要用于诊断；Silero threshold、ffmpeg `noise_db` 和 acoustic skeleton threshold 仍由静态配置提供。`fusion.enabled` 默认关闭，`AudioPreprocessor` 也不应直接覆盖 ASR 原始输入。

方案 B 的重点是接通控制闭环，而不是简单把阈值调低或默认打开降噪。

## 3. 设计原则

1. **ASR 和 VAD 双路输入**：VAD 可以使用轻度清理副本，ASR 默认保留原始 vocals，并支持低置信区域 A/B。
2. **证据加权而非简单投票**：Silero 负责语音概率，ffmpeg/RMS 负责能量边界，global word timestamp 负责已识别词的绝对时间，音乐检测负责降低纯能量证据权重。
3. **不修改原始 evidence**：自适应算法只生成候选、置信度和诊断，不把低置信检测结果伪装成物理事实。
4. **高噪声时优先扩大上下文和恢复**：不能通过单纯降低 VAD threshold 把更多噪声送入 ASR。
5. **所有自动决策可解释**：记录噪声特征、选用策略、候选阈值、证据来源、最终 coverage 和 recovery 原因。

## 4. 分阶段设计

### B1：噪声画像闭环

扩展 `LocalNoiseProfile`，至少包含：

- 局部噪声 dB 和 RMS MAD；
- 动态范围；
- 稳定噪声区比例；
- 音乐/谐波占比；
- speech-to-noise proxy；
- 估计可靠性和 fallback 标记。

输出按时间覆盖稳定区间，使用分位数、MAD、滞回和上下限夹持。估计失败时只回退配置阈值并降低 evidence confidence。

### B2：场景化多源边界融合

建立统一 boundary candidate：

```text
Silero speech probability
ffmpeg silence boundary
RMS onset/offset
global word timestamp
separation/music quality
        -> weighted boundary decision
        -> evidence + confidence + reason
```

不同场景采用不同权重：

- 干净 TTS：ASR 词时间和 Silero 为主，低干预；
- 演讲/评测：ASR 上下文和 Silero 为主，RMS 只做边界确认；
- 影视/音乐：降低 ffmpeg/RMS 权重，禁止纯能量证据单独创建字幕；
- 户外/远场：提高召回，但将低置信候选交给 ASR recovery。

### B3：VAD/ASR 双路预处理

引入明确的 `vad_audio` 和 `asr_audio`：

- `vad_audio`：可选 burst protection、轻度 spectral gate；
- `asr_audio`：原始 vocals、清理 vocals 二选一或局部 A/B；
- 以 coverage、`no_speech_prob`、logprob、术语命中和重复率比较 A/B；
- 清理后质量下降时自动回退原始输入。

音乐现场默认不使用强谱门，避免把人声高频和清辅音一起削掉。

### B4：低置信窗口恢复

触发条件包括：

- global word coverage 缺口；
- 物理 speech evidence 存在但 ASR 输出为空；
- `avg_logprob` 低、`no_speech_prob` 高或 `compression_ratio` 异常；
- 词时间跨越不连续物理边界；
- 语言概率与配置冲突；
- 文本重复或明显幻觉。

恢复顺序：扩大上下文 → 原始/清理音频 A/B → 备用后端/模型 → 局部 segmented recovery。每次恢复都记录窗口、尝试次数、候选结果和最终选择原因。

### B5：质量门和场景路由

方案 B 不直接修改全局默认值。新增场景策略时必须具备：

- 输入特征触发条件；
- 适用的 VAD/ffmpeg/fusion/预处理策略；
- 触发后的回滚条件；
- 与 TTS、演讲、影视、非中文基准的对比结果。

## 5. 不采用的直接改法

- 不把噪声越大简单映射为越低的 Silero threshold；
- 不全局启用 `fusion.enabled`；
- 不全局启用强降噪；
- 不把 `max_snap_distance` 直接扩大到 0.5 秒以上；
- 不用 LLM 代替声学边界和词级时间；
- 不用未经标注的“提升 20%-40%”作为验收标准。

## 6. 验收指标

方案 A 稳定后，对每个 B 子阶段做独立消融，至少记录：

- CER/WER、内容召回、幻觉字符率；
- start/end MAE、P95、超过 300 ms 的比例；
- speech evidence coverage、跨静音事件数、漏检时长；
- recovery 成功率、误恢复率、平均额外耗时；
- 干净 TTS 是否回退；
- 影视/音乐中非人声事件是否增加。

进入默认策略的门槛是：复杂场景至少一个主要指标改善，干净场景无显著回退，所有降级和恢复都可解释。

## 7. 预计实施顺序

```text
B1 噪声画像可靠性
  -> B2 多源边界候选
  -> B3 双路预处理
  -> B4 低置信窗口恢复
  -> B5 场景路由和默认策略
```

方案 B 只有在方案 A 的 global path、物理 provenance、实际 ASR path 统计和真实质量基准稳定后才进入实现。
