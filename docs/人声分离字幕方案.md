### 2.2 Open-Unmix umxhq（品质优先，MIT）

品质比 Spleeter 提升约 1–2 dB SDR，使用 `umxhq` 权重（MIT）：

```bash
pip install openunmix
```

```python
import torch
import torchaudio
import openunmix

model = openunmix.umxhq()
audio, sr = torchaudio.load('input.wav')
if sr != 44100:
    audio = torchaudio.functional.resample(audio, sr, 44100)
    sr = 44100

estimates = model(audio.unsqueeze(0))
vocals = estimates[0, 0]  # 第一轨为人声
torchaudio.save('vocals.wav', vocals.cpu(), sr)
```

## 三、VAD 语音检测

### 3.1 为什么必须用专业 VAD

长静音对 Whisper 时间轴的伤害是隐蔽但致命的：Whisper 的内部注意力机制在遇到超过 5–10 秒的连续静音时，容易出现时间戳偏移（timestamp drift），表现为字幕整体前移或后移、句尾被截断。因此**在人声分离之后、送入 ASR 之前，先用 VAD 切除所有长静音区间，只保留有语音的片段**，是整个方案精度的核心保障。

#### Silero VAD vs ffmpeg silencedetect

| 维度 | ffmpeg silencedetect | Silero VAD |
|------|---------------------|------------|
| 判断依据 | 纯能量/分贝 | 声学特征 + 神经网络 |
| 人声 vs 乐器 | 无法区分 | 可区分 |
| 低音量语音 | 阈值过高会丢失 | 能识别 |
| 对残留噪声 | 敏感 | 鲁棒 |
| 防时间轴漂移 | ❌ 长静音仍送入 ASR | ✅ 切除静音后再送 ASR |
| 计算开销 | 极低 | 低（CPU 实时，模型 < 2MB） |
| 协议 | GPL | MIT |

### 3.2 Silero VAD（推荐，MIT）

#### 使用示例

```python
import torch
import torchaudio

# Silero VAD — MIT 协议，模型 ~1.5MB
model, utils = torch.hub.load('snakers4/silero-vad', 'silero_vad')
(get_speech_timestamps, _, _, _, _) = utils

wav, sr = torchaudio.load('vocals_16k.wav')
speech_timestamps = get_speech_timestamps(
    wav, model,
    threshold=0.5,                  # 语音概率阈值
    min_speech_duration_ms=250,     # 最小语音段长度
    min_silence_duration_ms=400,    # 最小静音间隔
    return_seconds=True,
)
# → [{'start': 0.12, 'end': 2.34}, {'start': 3.10, 'end': 8.90}, ...]
```

#### 参数速查

| 参数 | 推荐值 | 调低时 | 调高时 |
|------|--------|--------|--------|
| `threshold` | 0.4–0.5 | 更多语音段，可能误检噪声 | 更少语音段，可能漏检轻声 |
| `min_speech_duration_ms` | 250 | 保留短促语气词 | 过滤更多短噪声 |
| `min_silence_duration_ms` | 300–500 | 切割更细，段更多 | 切割更粗，段更少 |

### 3.3 TEN VAD（低延迟，Apache 2.0）

2025 年发布，模型仅 306KB，声称语音起止过渡检测优于 Silero VAD，延迟低数百毫秒：

- 支持 C / Python / WASM（浏览器端可用）
- 较适合实时/流式场景、语音助手

### 3.4 fast-vad（极致速度，MIT / Apache 2.0）

Rust 实现 + SIMD 加速，速度比 WebRTC VAD 快几个数量级。有三种模式（permissive / normal / aggressive），适合嵌入式或大规模批量处理。

### 3.5 WebRTC VAD（轻量降级，BSD 3-Clause）

适合资源极端受限的场景（如树莓派、浏览器端），但不区分人声与乐器，精度不及神经网络 VAD：

```bash
pip install webrtcvad
```

```python
import webrtcvad
import wave

vad = webrtcvad.Vad(2)  # 0=normal, 1=low, 2=aggressive, 3=very aggressive
wf = wave.open("vocals_16k.wav", "rb")
assert wf.getframerate() == 16000 and wf.getnchannels() == 1

frame_ms = 30  # WebRTC VAD 仅支持 10/20/30ms 帧长
frame_bytes = int(16000 * 2 * frame_ms / 1000)

frames = []
while True:
    frame = wf.readframes(int(frame_bytes / 2))
    if len(frame) < frame_bytes:
        break
    is_speech = vad.is_speech(frame, 16000)
    frames.append(is_speech)

# 将帧级判定合并为语音区间（与 Silero VAD get_speech_timestamps 逻辑相同）
```

> **注意**：WebRTC VAD 仅输出帧级 bool 值（是否语音），不提供区间合并逻辑，需自行实现合并算法（可复用本文 Section 四的合并策略）。

### 3.6 ffmpeg silencedetect 降级方案

如果因环境限制（无 Python、无网络）无法安装任何 VAD 库，可用 ffmpeg 内置的 silencedetect 作为**最低配降级方案**。参数参考：

```bash
ffmpeg -i vocals.wav -af "silencedetect=noise=-30dB:d=0.5" -f null -
```

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| `noise` | **-35dB ~ -30dB** | 低于此音量视为静音，-30dB 较保守，-35dB 更灵敏 |
| `d` | **0.3s ~ 0.5s** | 静音持续超过此时间才视为断句点 |

> 限制：无法区分人声与乐器残留（纯能量判断），时间轴精度明显低于神经网络 VAD。仅在无法使用 Silero VAD 时作为最后备选。

## 四、片段合并策略

### 合并规则（自研逻辑，MIT）

```
if 相邻两段间隔 < min_silence_gap（推荐 0.4s）:
    → 合并为一段 （说话换气通常在 0.5s 以内）
if 合并后长度 > max_segment_length（推荐 30s）:
    → 在段内最长静音处切分
最后：两端各加 padding 100ms（防首尾音素被切）
```

### 可视化

```
VAD 原始区间:   ████ ██  ██████ ███ ████████
                     ↓ 合并间隔 < 0.4s
合并后:         █████████ ██████ ████████████
                     ↓ 切分 > 30s 的长段
最终:           █████████ ██████ ███████ █████
                     ↓ 两端 +100ms padding
输出:           █████████ ██████ ███████ █████
```

### 参数对照

| 参数 | 保守 | 激进 | 推荐 |
|------|------|------|------|
| min_silence_gap | 0.8s | 0.2s | **0.4s** |
| max_segment_length | 60s | 15s | **30s** |
| padding | 200ms | 0ms | **100ms** |

## 五、分段 ASR 识别

### 5.1 faster-whisper（推荐，MIT）

SYSTRAN 开发，CTranslate2 推理引擎，比原版 Whisper 快 4 倍、内存减半。

```python
from faster_whisper import WhisperModel

# 模型选择：large-v3（最高精度）或 medium（平衡）
model = WhisperModel("large-v3", device="cuda", compute_type="float16")

for i, (seg_start, seg_end, seg_wav) in enumerate(segments):
    segments_out, info = model.transcribe(
        seg_wav,
        language="zh",                   # 锁定语言，避免自动检测错误
        vad_filter=False,                # 关闭内置 VAD — 用外部 Silero VAD 精确控制
        word_timestamps=True,            # 词级时间戳
        beam_size=5,
        condition_on_previous_text=False,# 每段独立，避免跨段幻觉
    )
    for seg in segments_out:
        # seg.start / seg.end 是段内偏移
        global_start = seg_start + seg.start  # ← 核心映射公式
        global_end   = seg_start + seg.end
        print(f"[{global_start:.2f}s → {global_end:.2f}s] {seg.text}")
```

#### 关键配置

| 参数 | 值 | 原因 |
|------|-----|------|
| `vad_filter` | **False** | 外部 Silero VAD 更精确，避免内置 VAD 二次切割 |
| `word_timestamps` | **True** | 词级时间戳用于字幕对齐 |
| `language` | 指定代码 | `zh` `en` `ja` 等，跳过自动检测提升精度 |
| `beam_size` | 5 | 平衡速度与精度 |
| `condition_on_previous_text` | **False** | 每段独立，避免前段幻觉污染后段 |

## 六、时间轴映射与字幕拼接

### 映射公式

```
全局时间 = 片段在原始音频中的起始偏移 + 段内 ASR 时间戳
```

### 段间间隙处理

```
间隙 = T_B_start - T_A_end

策略：
  间隙 ≤ 0.2s  → A 字幕结束时间 = B 开始 - 1ms（无缝衔接）
  0.2s < 间隙 ≤ 1.0s → 保留自然停顿
  间隙 > 1.0s → 保留为段落间隔
```

### 字幕行规则

```
最小字幕时长：0.8s（过短合并到相邻）
最大字幕时长：5.0s（过长拆分）
最大字符数：  中文 ≤ 20 字/条，英文 ≤ 42 字符/条
```

### 输出格式示例

```srt
1
00:00:01,200 --> 00:00:04,500
大家好，欢迎收看今天的节目。

2
00:00:05,000 --> 00:00:08,300
今天我们来聊一聊人工智能。
```

### 8.1 校准步骤

```
1. 取一段 2–3 分钟的典型样本音频
2. 人声分离 → 16kHz mono WAV
```

## 十、常见问题与对策

### 10.1 句首/句尾吃字

**现象**：轻辅音（s, f, h, 气声）被 VAD 误判为静音切掉

**对策**：
- 增大 padding 到 150–200ms
- 降低 VAD threshold 到 0.3–0.4
- 降低 min_silence_duration_ms 到 200ms

### 10.2 乐器残留误检

**现象**：分离不彻底的乐器被 VAD 判定为人声，产生空识别段

**对策**：
- 提高 VAD threshold 到 0.6+
- 在人声分离后 VAD 前加 `noisereduce` 噪声抑制（见 9.2）
- ASR 后过滤：confidence < -1.0 log prob 的段丢弃
- 换用 Open-Unmix umxhq（分离更干净）

### 10.3 段间拼接突兀

**现象**：相邻字幕时间不连续

**对策**：
- 间隙 < 0.3s 时，前段字幕延伸到后段开始前 1ms
- 始终保留 padding，不在段边界硬切

### 10.4 长句被从中切断

**现象**：换气停顿超过 min_silence，一句话被切成两段

**对策**：
- 增大合并阶段的 min_silence_gap 到 0.6–0.8s
- 0.4s 可覆盖绝大多数换气停顿

## 十一、进阶优化

### 11.1 双重 VAD

```
粗切 (threshold=0.3) → 找到大范围语音区
精切 (threshold=0.6) → 在粗区内精确找起止点
→ 不丢内容 + 边界精确
```

### 11.2 噪声抑制预处理

在人声分离后、VAD 前，用 `noisereduce`（MIT）消除残留嘶声和底噪：

```python
import noisereduce as nr
from scipy.io import wavfile

rate, data = wavfile.read("vocals_16k.wav")
cleaned = nr.reduce_noise(y=data, sr=rate, stationary=False)
wavfile.write("vocals_cleaned.wav", rate, cleaned)
```

**参数建议**：非稳态模式（`stationary=False`）适合背景噪声有波动的场景；稳态模式适合持续底噪（如风扇声、电流声）。

### 11.3 多模型投票

对同一片段用 faster-whisper + Fun-ASR-Nano 分别识别，取置信度高的一致结果，降低单模型幻觉。
