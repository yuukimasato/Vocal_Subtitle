# 开始 结束 时长 文本

键盘快捷键

时间轴键位在小键盘（NumLock 任意状态均可），无小键盘时主键盘数字排等效。

小键盘 5播放当前字幕，到结束为止
小键盘 1试听开始点之前 500ms
小键盘 3试听结束点之后 500ms
小键盘 8停止播放
小键盘 4 / 6开始点前移 / 后移（Shift 微调 10ms）
小键盘 7 / 9缩短 / 加长当前句（Shift 微调 10ms）
小键盘 2 / 0下一句 / 上一句
小键盘 Enter提交编辑并停止试听
Space播放 / 暂停
← / →快退 / 快进 5s（Shift 1s）
, / .上一帧 / 下一帧
N在播放头处插入字幕
Delete删除选中行
Ctrl+D / Ctrl+M拆分 / 合并
L循环当前句
F列表跟随播放滚动
Ctrl+Z / Ctrl+Shift+Z撤销 / 重做
Ctrl+S按当前格式导出
Ctrl+滚轮缩放波形

双击字幕行可编辑文本与时间；拖拽波形区块边缘改时间，拖中间整体移动。

关于

字幕打轴工作台（Vocal Subtitle Timing Editor）——本地运行的网页版字幕打轴工具。

本工具为独立实现，未使用任何参考编辑器的源代码或美术资源。
